# Reference Logo Library

Place reference logo images here for brand detection.

**Naming convention:** Use the brand name with underscores, e.g.:
- `national_bank.png` → detected as "National Bank"
- `kazpost.png` → detected as "Kazpost"
- `government_seal.png` → detected as "Government Seal"

Supported formats: PNG, JPG, JPEG, BMP, WEBP.

The logo detector uses ORB feature matching — high-contrast logos
with distinct shapes work best. Minimum recommended size: 100×100px.
